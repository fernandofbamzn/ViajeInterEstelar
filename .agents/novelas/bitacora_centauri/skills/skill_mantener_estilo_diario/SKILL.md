# Skill: Mantener Estilo de Diario

## Objetivo
Garantizar que todo el texto generado se ajuste a las reglas de formato de un diario o bitácora de viaje.

## Pasos
1. Revisar la entrada del texto para asegurar que esté en primera persona.
2. Comprobar la presencia de marcadores temporales o de posición.
3. Sugerir o insertar placeholders de imágenes donde el texto describa elementos visuales impactantes.
