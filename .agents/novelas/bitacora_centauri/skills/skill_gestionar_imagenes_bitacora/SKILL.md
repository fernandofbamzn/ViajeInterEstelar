# Skill: Gestionar Imágenes de Bitácora

## Objetivo
Identificar momentos visualmente clave en la narración y proponer prompts o descripciones para imágenes.

## Pasos
1. Leer la entrada del diario.
2. Extraer paisajes, vehículos o personajes destacados.
3. Crear un bloque `[IMAGEN: ...]` con la descripción detallada.
