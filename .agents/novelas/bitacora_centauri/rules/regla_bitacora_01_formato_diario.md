# Regla: Formato de Diario de Viaje

1. **Perspectiva:** Debe estar escrito en primera persona, como una narración de las experiencias vividas.
2. **Fechado y Estructura:** Cada entrada debe estar claramente fechada o ubicada temporalmente (por ejemplo, "Día 45, Órbita de Júpiter").
3. **Imágenes:** Se deben reservar espacios o menciones para incluir fotografías o diagramas del viaje (`[IMAGEN: Descripción detallada]`).
4. **Tono:** Personal, reflexivo, pero con la precisión técnica propia de una bitácora espacial.
